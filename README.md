# QuartzKV

Official implementation of **QuartzKV: Low-Rank KV-Cache Compression for Long-Context
Inference** (ICLR 2025).

**Release status: public release (v1.0).** Code, evaluation scripts and configuration
files are available in this repository.

## Contents

- `src/` - low-rank projection, cache compression and decoding utilities
- `configs/` - model and compression configurations
- `experiments/` - long-context evaluation scripts
- `data/` - notes on the evaluation corpora
